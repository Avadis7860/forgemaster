# Méthode — facette Review / Sécurité

1. **Cadre le diff** — les lignes **introduites** seulement ; charge le contexte autour (`codemap where`).
2. **Cherche par axes** — correctness, sécurité (secret/entrée non validée), régression, réutilisation manquée.
3. **Réfute avant de reporter** — citation verbatim + tentative de réfutation ; pas de preuve → pas de finding.
4. **Classe** — sévérité honnête, cap sur les nits ; un rouge légitime, c'est le gate qui fait son travail.
