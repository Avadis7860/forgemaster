# Méthode — facette Doc

1. **Audience d'abord** — pour qui cette page, quelle décision sert-elle ? Écris pour elle.
2. **Intention avant mécanique** — la section « pourquoi » précède le « comment ».
3. **Une section = une idée vérifiable** — pas de prose molle ; lie les pages entre elles.
4. **Fraîcheur** — après avoir touché `docs/`, `docsmap build` (l'anti-archéologie en dépend).
